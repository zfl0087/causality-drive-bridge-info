隐私说明

应用：Weight of Causality Drive Bridge。更新日期：2026-10-15。本说明对应个人自用及指定协作者使用的部署。

访问与用途

工具使用所有者授权的 Google Drive API 访问文件内容和元数据。读取版本化文本副本、修改提案及明确请求检查的媒体；在配置的交换目录中创建或更新阅读副本和处理回执。Drive 授权范围可能大于这些目录，目录限制由程序执行。

存储与共享

OAuth 客户端密钥和刷新令牌保存在所有者控制的本地配置及 GitHub Actions 加密 Secrets 中。仓库中获准运行自动任务的协作者可能通过工作流使用这些权限。授权运行的 GitHub Actions 会处理必要文件；媒体检查使用运行器临时目录。正式文本、提案、处理记录及版本历史可能保存在所有者配置的 GitHub 仓库与 Drive 目录中，直至所有者清理。

指定协作者可以通过已授权的 AI 服务访问分享的阅读副本或媒体；相关服务的处理规则由其隐私政策及账号设置决定。工具不将 Google 用户数据出售或用于广告定向；日志应避免输出令牌及不必要的文件正文。

撤销与清理

所有者可在 Google 账号的第三方连接设置中撤销本工具访问，并停用工作流、删除 GitHub Secrets 及本地授权配置。撤销授权不会自动删除既有 Drive 文件、Git 历史、处理记录或第三方服务中的副本；这些内容需在对应服务另行清理。联系应用所有者可使用 Google 授权页面列出的用户支持邮箱。
